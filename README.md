# KCD в Minecraft (приватный проект)

Кооперативный порт Kingdom Come: Deliverance 1+2 в Minecraft для игры с друзьями.
**Приватно, не публиковать** (сюжет и персонажи принадлежат Warhorse Studios).

- Контекст и решения — [`CONTEXT.md`](CONTEXT.md)
- Концепция пролога — [`docs/prologue-concept.md`](docs/prologue-concept.md)
- Исследования — [`docs/`](docs/)

## Как установить (для друзей)
Скоро: скачать архив последней версии из раздела **Releases** и распаковать в папку `.minecraft`,
затем выбрать версию «KCD» в TLauncher. Подробная инструкция появится с первой версией.
