# Контекст проекта: Kingdom Come: Deliverance в Minecraft

## Идея
Перенести KCD1 и KCD2 (мир, механики, сюжет) в Minecraft так, чтобы это выглядело **аутентично-ванильно**,
и проходить сюжет **в кооперативе с друзьями**. Сюжет — через квесты (общие на команду) и диалоги с NPC.

Пользователь (znewk) общается по-русски, опыта в Java нет. **Всё делает Claude**: код, рельеф и карта, постройки
«по канону», квесты, диалоги, русский текст. Пользователь тестирует и присылает скриншоты/замечания.
Игру без разрешения пользователя не запускать. Запуск — через TLauncher (как у сборки Homestead,
см. `C:\Users\Arlan\AppData\Roaming\.minecraft\claude\CONTEXT.md` — там особенности TLauncher).

## Окружение
- ПК пользователя (= ориентир «средний ПК» для оптимизации): i5-10400F, GTX 1650 4 ГБ, 16 ГБ ОЗУ, Windows 11.
  TLauncher 2.9378. Установлены (03.10.2026): JDK 21 (Temurin), Git, GitHub CLI (вход — аккаунт znewk).
- Репозиторий: https://github.com/znewk/kcd-minecraft (приватный). Мод — папка `mod/` (NeoForge MDK,
  mod_id `kcd`, пакет `com.znewk.kcd`); сборка: `mod\gradlew.bat build` → `mod\build\libs\kcd-*.jar`.
- Пробный запуск: `tools\testlaunch.ps1` (как TLauncher; ждёт главное меню/краш, закрывает игру).
  Пользователь разрешил запускать его самостоятельно (03.10.2026) — предупреждать в чате, что откроется окно.
- TLauncher (из опыта Homestead): модпак = версия с блоком `modpack` в `versions\<имя>\TLauncherAdditional.json`,
  папка игры = `versions\<имя>\`; TLauncher сам качает MC, библиотеки, ассеты, Java.
  Память — ставить в настройках самого TLauncher (он перезаписывает TLauncherAdditional.json).

## Решения, принятые на обсуждении (03.10.2026)
- **Аудитория — только друзья**, не публичный релиз → канонический сюжет, имена, места можно использовать.
  Публиковать нельзя (IP Warhorse Studios); если пользователь захочет публиковать — переделать в «по мотивам»
  (реальная история Богемии 1403 г. + свои персонажи).
- **Кооп-адаптация**: прогресс квестов общий на команду; с NPC говорит подошедший, остальные видят диалог;
  один игрок — Индржих, остальные — его спутники; масштабирование боёв/наград под число игроков.
  **Отряд — до 12 игроков.** Спутники в прологе — **тоже сыновья Мартина** (братья Индржиха).
- **Цель — повторить всё** (все механики, весь мир, свой текстурпак и шейдеры), но **главный принцип:
  «это Minecraft с уклоном в KCD2»**. Каждая механика — привычная майнкрафтовская основа + поправка в духе KCD2,
  а не точная копия интерфейсов и систем KCD. Ориентир по механикам — KCD2 (не KCD1).
  Примеры: бой — ванильный с поправками; торговля — окно в стиле жителей, но с грошами и торгом;
  инвентарь — ванильная сетка + слои одежды/доспехов и вес.
- **Формат**: приключенческая карта + свой мод + свой ресурспак + шейдеры (не сборка из сотни модов).
- **Готовый мод = только инструмент, содержание — в точности KCD.** Ощущение и управление — майнкрафтовские,
  но правила, числа, предметы, названия, тексты, рецепты, цены, NPC, квесты — как в KCD (ориентир KCD2).
  Всё «чужое» из готовых модов (лишние предметы, рецепты, мобы, механики, интерфейсы не в стиле KCD) —
  убираем или прячем. Получается не «похожий мод», а KCD, собранный на его движке. Если мод нельзя настроить
  под KCD точно — не берём его, ищем другой или пишем своё.
- **NPC как в KCD — ключевая система, пишем свою** («мозг» NPC; готовый мод максимум как тело/скин/окно диалога):
  - **Характер**: черты (жадный, трусливый, набожный, вспыльчивый...) влияют на диалоги и реакции;
  - **Память**: помнит действия каждого игрока (помог, обманул, украл, ударил, был замечен на преступлении,
    в чём был одет/испачкан ли кровью) и группы; со временем часть забывает, как в KCD;
  - **Репутация**: личная к NPC + у деревни/города + у фракции (как в KCD2);
  - **Распорядок дня**: сон, работа, церковь, корчма, реакция на время суток, погоду, события;
  - **История и лор**: каноническая биография, родственники/друзья/враги среди других NPC, слухи;
  - **Скрипты**: сюжетные сцены, поведение в квестах, особые реакции.
  **Состав — повторяем всех значимых NPC по канону** (имена, внешность → скин, характер, биография,
  роль в сюжете, где живёт и чем занят), в три уровня проработки:
  1. **Сюжетные** (Индржих, Ганс Капон, Радциг Кобыла, сэр Дивиш, Тереза, Мартин, Бара, Матей, Иштван Тот,
     Сигизмунд, Вацлав IV, Ян Жижка, Катерина, Отто фон Берговиц и т.д.) — полностью по канону: все сюжетные
     диалоги, сцены, поведение;
  2. **Побочные квесты, торговцы, мастера, стража** — по канону: свои квесты, диалоги, распорядок;
  3. **Фоновые жители** — из шаблонов (крестьянин, ремесленник, монах...), но тоже с памятью, распорядком
     и характером; лор — общий для деревни/города.
  Диалоги — текстом на русском по каноническому сценарию (озвучки нет; возможно позже).
  Данные каждого NPC — в отдельном файле (лор, характер, распорядок, диалоги), чтобы легко дописывать.
  Оптимизация: полный ИИ только рядом с игроками; вдали NPC «виртуальные» — положение считается по
  расписанию без живой сущности и без нагрузки.
- **Готовые моды вместо своих, где возможно** (экономия месяцев работы). Порядок выбора для каждой механики:
  1) готовый мод + настройка (конфиги, датапаки, скрипты KubeJS, переопределения в ресурспаке);
  2) готовый мод + наш небольшой аддон поверх него;
  3) свой код — только если подходящего мода нет (специфика KCD: сохранение шнапсом, алхимия, связка всего).
  Чужие .jar не правим и не форкаем (лицензии + чтобы спокойно обновлять) — дорабатываем «снаружи».
  Каждый мод проверяем: есть ли под нашу версию/загрузчик, совместим ли с остальными, сколько ест FPS/RAM.
  Тяжёлые моды не берём, даже если удобные.
- **Стилистика (03.10.2026, по примерам пользователя — превью-арты сборок на YouTube):** устройство экранов —
  KCD2 (меню справа, выбранный пункт на золотом свитке, подсказка между золотыми линиями, панели-пергамент,
  щиты-иконки); вид — «превью-арт Minecraft»: объёмные блочные буквы с толстой тёмной обводкой, подзаголовок
  на цветной ленте, яркие тёплые сцены. Палитра: пергамент #EADFC8, золото #C9A24A, тёмно-красный #B3262A,
  тёмный сине-серый для панелей. Графика генерируется кодом: `tools/art/GenArt.java` (+ `Preview.java`).
  Главное меню: `KcdTitleScreen`; фон — временная панорама (замок на двух скалах, поля, деревня),
  заменить панорамой из нашей Скалицы, когда она будет построена. Ранний экран загрузки NeoForge (лиса,
  заголовок «NeoForge Loading») не меняется без своего «early window provider» — отложено, пока только тёмный фон.
- **Интерфейс — KCD2, адаптированный под Minecraft** (свой, т.к. готовые моды так не выглядят):
  устройство экранов и логика — как в KCD2, а вид — майнкрафтовский: пиксельные иконки 16x, ванильный шрифт,
  рамки и кнопки в стиле окон Minecraft, но в тёплых «пергаментных» тонах KCD.
  - **Карта мира** — пергаментная карта в духе KCD2, нарисованная пикселями (не оригинальная картинка), туман неразведанного,
    открытые места, метки квестов, свои метки; позиции игроков отряда.
  - **Компас вверху экрана** — как в KCD2 (миникарты в KCD2 нет): стороны света, маркеры квестов,
    ближайшие места. Многие цели — только устным направлением, как в KCD2.
  - Подробный справочник по интерфейсу и звуку KCD2 — `docs/research-kcd2-ui-audio.md`.
  - **Журнал квестов** — как в KCD2: записи в стиле дневника, основные/побочные/выполненные, отслеживаемый
    квест; + **кодекс** (люди, места, история). Логику квестов можно держать на FTB Quests, но его окно
    скрыто — игрок видит только наш журнал.
  - Инвентарь, торговля, диалоги, характеристики, алхимия, меню — по устройству как в KCD2, по виду —
    Minecraft (пиксели, ванильные окна в пергаментных тонах), удобные под мышь/клавиатуру Minecraft.
  Xaero's из списка кандидатов, скорее всего, убираем — нужен вид KCD2.
- **Музыка и звук — как в KCD2.**
  - **Динамическая музыка** (своя система, как в KCD2): музыка зависит от ситуации — исследование днём/ночью,
    деревня/город, корчма, церковь, напряжение (враги рядом, погоня), бой, сюжетные сцены; плавные переходы
    между треками, тишина между ними (не играет без остановки). Ванильная музыка Minecraft отключена.
    Правила KCD: бой — всегда с музыкой; в деревнях музыка чередуется с тишиной; в лесу — в основном
    тишина и природа; плавный переход ~15 с, вход в бой ~1 с. Музыка внутри мира (хор, музыканты в
    корчме) — только там, где её реально исполняют.
  - **Треки**: оригинальный саундтрек KCD2 не раздаём. Основа — средневековая музыка со свободной
    лицензией (CC0/CC-BY: лютня, колёсная лира, флейты, барабаны, хоралы) в духе KCD2; кандидаты —
    RandomMind (CC0), Kevin MacLeod и Alexander Nakarada (CC BY, указать авторов); Pixabay не берём.
    **Решено: и то и другое.** Сейчас — свободные треки, подобранные максимально похоже на KCD по звучанию
    и настроению; плюс «личная папка музыки»: кто купил саундтрек, кладёт свои файлы (не раздаём),
    система играет их по тем же ситуациям.
  - **Звуковое окружение**: живые деревни и города (голоса, ремесло, кузница, колокола, скот, рынок),
    природа по времени суток и погоде (птицы, ветер в лесу, сверчки ночью, река), корчма (гул голосов, кружки),
    бой (сталь, доспехи), шаги по разным поверхностям, звуки интерфейса (пергамент, монеты).
    Источники — ванильные звуки Minecraft + свободные библиотеки (CC0, напр. freesound.org); всё в стиле
    Minecraft и лёгкое для системы.
- **Текстурпак**: за основу — готовые ванильные/средневековые паки (если лицензия позволяет личное
  использование), дорисовываем недостающее; свой, средневековая Богемия в ванильном стиле (16x, палитра и дух ванилы) — блоки, предметы
  (оружие, доспехи, одежда KCD), интерфейс, NPC.
- **Шейдеры**: через Iris (есть под NeoForge и Fabric). Не пишем свой — берём готовый (кандидаты:
  Complementary, BSL, Makeup Ultra Fast) и настраиваем под KCD (тёплый свет, туман, вода, небо Богемии); пресеты «слабый / средний / ультра» под разные ПК друзей.
- **Оптимизация — приоритет №1, с самого начала**: всё должно работать быстро и слабо нагружать систему.
  Sodium/Embeddium, Lithium, FerriteCore, ModernFix и т.п.; мир предзагенерирован (Chunky).
  Свой мод пишем экономно: без тяжёлой логики каждый тик, NPC «засыпают» вдали от игроков, минимум
  сущностей, лёгкие модели/текстуры. Шейдеры и Distant Horizons — **опциональные**, по умолчанию выключены
  (включают только те, у кого мощный ПК). Регулярно меряем FPS/TPS/RAM (spark) на слабом и сильном ПК;
  фича, которая заметно роняет FPS, — переделывается или упрощается.
- **Мир и постройки — KCD как образец, результат — аутентичный Minecraft-порт.** Не копируем модели KCD
  один в один, а берём из KCD планировку и узнаваемость и строим «как построил бы хороший майнкрафтер»:
  ванильные блоки и пропорции Minecraft (двери в 2 блока, крыши из ступенек/плит, детали блоками),
  но расположение, силуэты, характер мест — как в KCD, чтобы всё сразу узнавалось.
  - **Планировка мира — по картам KCD, а не реальной географии** (в KCD мир сжат и переставлен).
    Где деревни, дороги, реки, леса, холмы — по игровой карте KCD; масштаб ~1 метр = 1 блок.
    Карты: KCD1 (Ратае/Сазава/Тальмберг), KCD2 (Троски и Кутна-Гора).
  - **Источники-образцы**: игровые карты KCD1/KCD2 (картинки высокого разрешения), скриншоты, видео
    прохождений, вики. Игры на ПК не найдены (проверено 03.10.2026: Steam C:/D:, GOG, Epic) — если будут
    установлены, можно дополнительно сверяться с файлами уровня (карта высот, положения объектов).
  - **Рельеф**: строим по форме игровой карты (холмы, долины, реки на своих местах); реальные данные высот
    (DEM) можно использовать только как «природную фактуру», подогнанную под планировку KCD.
  - **Постройки** — генерация кодом по образцу (план, размеры, силуэт, расположение) в Minecraft-стиле,
    проверка рендером сверху и сравнение с картой KCD, доработка ключевых мест по скриншотам.
  Проверки «без багов»: сверка с оригиналом, нет дыр/парящих блоков, все дороги проходимы, NPC
  доходят по своим маршрутам, нет мест, где можно застрять или выпасть за карту.
- **Оригинальные ассеты KCD не используем** — всё перерисовываем в пиксельном стиле Minecraft
  (иконки, карта, элементы интерфейса). От KCD берём только образец: что изображено, расположение, цвета, настроение.
- **Две отдельные программы**: (1) **обновлятор «KCD»** — у каждого игрока, только ставит/обновляет
  сборку для TLauncher; (2) **лаунчер сервера** — только у хоста: запуск сервера, миры, прогресс, игроки, роли.
- **Раздача друзьям — установщик/обновлятор «KCD»** (один `.exe`), запуск остаётся через TLauncher.
  Свой лаунчер на основе TLauncher невозможен (закрытый код); свой лаунчер с офлайн-входом не делаем.
  Обновлятор: находит `.minecraft`, ставит загрузчик + мод + ресурспак + карту → в TLauncher появляется
  версия «KCD»; при обновлении докачивает только изменённые файлы (хостинг — GitHub/Google Drive);
  опционально автоподключение к серверу. Делаем, когда будет что раздавать (после первого рабочего куска пролога).
  Альтернатива на будущее: брендированная сборка Prism Launcher (open source), но там нужен аккаунт Microsoft.
- **Лаунчер сервера для хоста** (отдельный `.exe`): одна кнопка «Запустить сервер» — ставит/обновляет
  выделенный сервер с модом и картой, запускает его, показывает адрес для друзей, консоль, игроков,
  кнопки «стоп / бэкап / обновить». Бэкапы мира автоматически.
  - **Миры (прохождения) хранятся и управляются в лаунчере**: создать новое прохождение (KCD1 / KCD2),
    выбрать, переименовать, скопировать, удалить; список сохранений (шнапс-точки + авто-бэкапы) с откатом
    к любому.
  - **Прогресс прохождения виден в лаунчере**: текущий акт и сюжетный квест, выполненные/активные квесты,
    % прохождения, время в игре, открытые места, дата последней игры, состав отряда и персонажи игроков
    (уровни навыков, гроши, репутация).
  - **Игроки и роли**: сервер запоминает каждого игрока (ник + пароль) и его персонажа в этом прохождении —
    навыки, инвентарь, репутацию, память NPC о нём. При первом входе в прохождение игрок выбирает роль:
    **Индржих** (только один) или **спутник** (свой персонаж: имя, внешность из набора эпохи, короткая
    предыстория). Хост в лаунчере видит и меняет роли (например, передать Индржиха на сессию).
  - **Сюжет** привязан к прохождению: состояние всех квестов, сюжетных выборов, NPC и мира хранится
    в мире и не зависит от того, кто сейчас онлайн.
- **Подключение из интернета без Radmin/Hamachi**: встроенный туннель **playit.gg** (бесплатный, не нужен
  проброс портов и «белый» IP, работает при CGNAT) → друзья получают постоянный адрес вида `xxx.joinmc.link`
  и вводят его в Minecraft. Запасной вариант — UPnP-проброс порта, если роутер позволяет.
  Т.к. у всех TLauncher, сервер в `online-mode=false` → обязательно whitelist + мод входа по паролю,
  чтобы никто чужой не зашёл под ником друга.
## Кооп: как это играется (черновик, уточнить в концепции пролога)
- **Отряд**: хост создаёт отряд, прогресс сюжета и квестов общий. Один игрок — **Индржих** (главный голос
  в сюжете), остальные — его **спутники**. Роль выбирается при первом входе и запоминается сервером
  (см. «Лаунчер сервера»). Если игрок-Индржих не пришёл — роль на сессию можно передать другому.
- **Диалоги**: говорит тот, кто подошёл к NPC; все игроки рядом (радиус ~10 блоков) видят диалог у себя на
  экране. Проверки навыков — по навыкам говорящего. В **сюжетных** выборах решает Индржих, остальные могут
  «подсказать» (их вариант подсвечивается у него). NPC занят, пока с ним говорит один игрок.
- **Кат-сцены**: своя система камеры (кинематографичная камера по пути, полосы сверху/снизу, NPC играют
  сцену). Перед сюжетной сценой — **сбор отряда**: точка сбора + «Готов?» у всех (или таймер, после которого
  отставших телепортирует). Во время сцены игроки неуязвимы и заморожены, у всех она идёт синхронно
  (сервер ведёт таймлайн). Пропуск — только если все нажали «пропустить». Чанки сцены подгружаются заранее.
  Кто подключился посреди сцены — сразу попадает в её конец/следующий шаг.
- **Сюжетные «ворота»**: ключевые шаги сюжета продвигаются только когда отряд собран; побочки, торговля,
  крафт, исследование — можно по одному, в любом месте карты.
- **Сохранение шнапсом в коопе**: сохранение = общая контрольная точка отряда (позиции, инвентари, квесты,
  NPC, репутация). Мир в режиме приключения (блоки не ломаются) — поэтому откат к сохранению реален и лёгкий.
- **Смерть**: игрок падает «раненым», товарищи могут поднять (перевязать). Если пали все — загрузка
  последнего сохранения для всего отряда.
- **Бой**: сила и число врагов масштабируются под число игроков.
- **Лут и награды**: лут в сундуках/с тел — у каждого свой (нет ссор); награда за квест — каждому.
  Гроши — личные, но можно передавать.
- **Репутация и преступления**: за преступление отвечает тот, кто его совершил; но NPC запоминает и его
  спутников («был с вором») — общая репутация отряда тоже немного падает.
- **Время**: сон/ожидание часов — когда согласны все (голосование), как ванильный сон.
- **Связь**: голосовой чат по близости (мод Simple Voice Chat — кандидат) — слышно тех, кто рядом, как в игре.
- **Тесты кооп-сцен**: два клиента локально + сервер; потом проверка с друзьями.

## Техническая основа — итоги проверки (03.10.2026)
**Решено: Minecraft 1.21.1 + NeoForge** (подтверждено пользователем 03.10.2026).
**Хранение и раздача: приватный репозиторий GitHub** (исходники) + **GitHub Releases** (готовые архивы:
сборка, мир, музыка — отдельными файлами, каждый < 2 ГБ). Друзья скачивают архив и распаковывают в
`.minecraft`; позже обновлятор качает оттуда же. Моды в будущем — напрямую с Modrinth.
- KubeJS 7 и Lightman's Currency есть только под NeoForge; Sodium, Iris, Lithium теперь официально под
  NeoForge → оптимизация не хуже Fabric. 1.20.1 Forge хуже: там вместо Sodium/Iris заброшенные Embeddium/Oculus.
- TLauncher запускает NeoForge (через официальный установщик). Минусы: команда NeoForge не помогает
  пользователям TLauncher; NeoForge при установке собирает пропатченный клиент в `libraries/` → обновлятор
  должен либо запускать установщик NeoForge, либо раздавать готовые `libraries`. Своя версия «KCD» —
  копия JSON NeoForge с другим `id` и `inheritsFrom: "1.21.1"` (проверить в TLauncher).
- Все кандидаты есть под 1.21.1 NeoForge и живые: FTB Quests/Teams, KubeJS, Easy NPC, Epic Knights,
  Better Combat, Pufferfish's Skills, Lightman's Currency, Guard Villagers, Simple Voice Chat, Iris (beta),
  Sodium, Lithium, FerriteCore, ModernFix, Distant Horizons, Chunky, spark, GeckoLib.
  Tough As Nails — ветка 1.21.1 заморожена (2024), но рабочая. Embeddium не нужен (заброшен → Sodium).
- Вход по паролю (offline-mode) под NeoForge: EasyAuth нет; кандидаты Auth (`auth`), Login System,
  Sol's AuthLogin — протестировать.
- playit.gg: бесплатно, агент открытый (BSD-2), управляется из командной строки → можно встроить в лаунчер
  сервера. Адрес для игроков вида `xxx-xxx.gl.joinmc.link` без порта. У некоторых провайдеров
  ошибка «Unknown host» — лечится сменой DNS.
