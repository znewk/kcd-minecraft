# Личная музыка в KCD (только на своём компьютере)

Игра умеет играть **твои собственные музыкальные файлы** вместо свободных треков сборки — по ситуациям
(меню, день, ночь, деревня, корчма, бой и т.д.). Эти файлы остаются только у тебя: они не входят в сборку,
не попадают на GitHub и в архив для друзей. Каждый игрок подключает свою музыку сам.

## Что нужно
- Папка с музыкой (`.mp3`, `.ogg`, `.wav`, `.flac`, `.m4a`), например `Documents\music`.
- ffmpeg (уже установлен; если нет — в PowerShell: `winget install Gyan.FFmpeg`).
- Проект `Documents\KCD-Minecraft` (там скрипт и таблица).

## Подключить
1. Закрой игру.
2. Win+R → `powershell` → Enter.
3. Вставь и нажми Enter:
   ```
   & "$env:USERPROFILE\Documents\KCD-Minecraft\tools\import-music.ps1" -Source "$env:USERPROFILE\Documents\music"
   ```
4. Скрипт:
   - находит треки по названиям из таблицы `tools\music-map.json` (номер в начале имени и регистр не важны);
   - переводит их в формат игры (.ogg);
   - собирает папку `%appdata%\.minecraft\versions\KCD\kcd\music_pack`;
   - в конце пишет, сколько треков в каждой ситуации и какие файлы не попали в таблицу.
5. Запусти «KCD». В ситуациях, где есть твои треки, играют только они; в остальных — свободные треки сборки.

## Таблица «трек → ситуация»
Файл `tools\music-map.json`. Ключ — ситуация, значение — список названий (часть имени файла).
Один трек можно указать в нескольких ситуациях. После правки — снова запусти команду из шага 3.

| Ситуация | Когда играет |
|---|---|
| `menu` | главное меню |
| `explore_day` | путь, поля днём |
| `explore_night` | ночь |
| `village` | деревня* |
| `town` | город, рынок* |
| `tavern` | корчма, праздник* |
| `church` | церковь, монастырь* |
| `camp` | военный лагерь* |
| `tension` | рядом опасность |
| `combat` | бой |
| `fistfight` | кулачная драка* |
| `chase` | погоня, верхом* |
| `victory` | после победы* |
| `cutscene` | сюжетные сцены* |

\* включаются автоматически, когда на карте появятся места/кат-сцены; до тех пор — командой в игре
`/kcdmusic <ситуация>` (например `/kcdmusic tavern`), вернуть автоматику — `/kcdmusic auto`.

## Убрать
Удали папку `%appdata%\.minecraft\versions\KCD\kcd\music_pack` — вернутся свободные треки.
